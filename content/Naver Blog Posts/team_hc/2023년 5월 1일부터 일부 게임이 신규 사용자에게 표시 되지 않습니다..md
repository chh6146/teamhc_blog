신규 사용자 여러분은 아래의 신규 사용자 미노출이 되어있는 게임 다운로드 받으시면 이후에도 즐길 수 있습니다.
​
​
​
안녕하세요, Team HC 입니다.
​

> 🔗 **[Google Play 앱의 대상 API 수준 요구사항 - Play Console 고객센터](https://support.google.com/googleplay/android-developer/answer/11926878?hl=ko)**
> Google Play 앱의 대상 API 수준 요구사항 원활한 전환을 위해 앱 검색 가능성을 위한 시정 조치의 기한이 2022년 11월 1일에서 2023년 1월 31일로 연장될 예정입니다. 대상 API 수준을 31 이상으로 높이기 위해 앱을 업데이트하는 데 시간이 더 필요한 경우 연장을 요청하실 수 있습니다. 2023년 5월 1일까지 모든 Google Play 사용자를 대상으로 앱이 검색될 수 있도록 연장 요청을 제출해 주시기 바랍니다. Play Console 받은편지함 메시지에서 각 앱의 기한 연장 요청 양식으로 연결되는 링크를 확...
> *support.google.com*

Google Play 정책으로 인해, 2022년 11월 1일 이후 API 31 이하의 어플리케이션이 신규 사용자에게 표시 되지 않습니다. 기존에 한 번이라도 다운로드 받으셨던 분은 정상적으로 표시가 됩니다.
본래 Team HC 게임은 여태껏 API 28을 타겟으로 하고 있었고 (Andorid 9) 그렇기에 위 사항에 모든 게임이 해당 되어 모든 게임이 신규 사용자에게 표시 되지 않고 있었습니다.
​
Ren'Py로 만든 게임들은 다시 컨버팅하여 재업로드 해보니 API 33을 가리키고 있어 (Android 13) 문제 없이 등록이 되지만.
기존 아르테미스 엔진으로 제작 된 게임들은 다시 업로드 하는 것이 불가능한 상황이라 일부 게임이 신규 사용자에게 표시 되지 않습니다.
​
기존 사용자는 정상적으로 표시 되기에 5월 1일이 되기 전, 아래의 표를 확인하여 기존 게임들을 한 번씩 다운로드 받으시는 걸 추천합니다.
​
​
​
아래는 현재 ​Team HC에서 서비스 중인 게임의 목록입니다.
참고해서 아직 다운로드 받지 않은 게임은 미노출 되기 전, 한 번 다운로드 받아서 라이브러리에 등록만 하시면 됩니다.
[표]
​
2023년 3월 13일 현재, 테스트로 '어떻게 봐도 내 인생은 너무 불행하다 2'만 API 타겟 33으로 지정하여 전체 공개를 한 상태이며, 큰 문제가 없는 한 모든 게임로 순차 업데이트 진행 할 예정입니다.
​
​
추가적으로 업로드 되는 Ren'Py 게임은 일괄 7.5 최신 버전인 7.5.3버전으로 업데이트 될 예정이며
몇몇 게임은 호환이 되지 않은 명령어 때문에 발견하지 못한 버그가 있는 부분이 있을 수 있습니다.
메일로 제보해주시면 바로 수정해서 업데이트 반영할 예정입니다.
​
현재 제작 중인 유나 다이어리의 경우도 7.5.3으로 제작 중이며, 이후에 개발 되는 게임은 렌파이 최신 버전인 8.0 버전으로 개발 될 예정입니다.

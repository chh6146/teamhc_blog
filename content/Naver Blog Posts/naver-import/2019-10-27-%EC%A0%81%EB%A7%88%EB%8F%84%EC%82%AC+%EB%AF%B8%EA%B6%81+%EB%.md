# 적마도사 미궁 대모험 - 개발일지 05 [일부 디자인]

안녕하세요, **Team HC 하언**입니다.

오늘은 일부 디자인을 공개하려고 합니다.

디자인 작업이 생각보다 많이 걸리고 있습니다. 어떤 테마로 해야 할지도 최근이 되어야 겨우 정할 수 있게 되어 조금 시간이 더딥니다.

그렇지만 만족스러운 결과물이 나와서 매우 좋습니다.

전체적으로 붉은색 계통으로 통일을 하였고 세로 모드에서도 불편함이 없이 사용할 수 있게

기존 휴대폰의 런쳐의 형태를 가져왔습니다.

iOS 발매를 하게 된다면 전체적으로 위로 당기는 형태가 되어야겠지만.

아직은 안드로이드만 발매할 예정이기에 그렇게까지 신경 쓰지 않아도 괜찮을 것 같습니다.

게임 내부 화면도 계속해서 고민중입니다.

어두운 화면에 밝은 글씨를 적어서 눈을 덜 피로하게 할지.

혹은 책을 읽는 느낌으로 흰 화면에 검은 글씨를 할지 (그렇지만 눈이 확실히 피로한 편입니다.)

둘 다 옵션으로 선택 가능하게 하는 방법도 있지만 이렇게 하기 위해서는 게임을 껐다 켜야 하는 불편함이 있습니다.

그런 불편함을 감수하더라도 넣는 게 맞을지 엄청 고민중입니다.

더불어 이 게임을 만들면서 이전에 기획만 하였던 게임들이 몇 개 있는데.

지금과 같은 환경이라면 천천히 만들 수 있을 것 같습니다.

현재 게임의 제작이 끝나면 공개할 수 있을 것 같습니다!

감사합니다.

# 앞으로 Team HC에서 발매되는 게임의 UI가 살짝 변경 됩니다.

**Team HC / 수호령의 올바른 취급 방법! 사이드 스토리 2**

**발매일** : 7월 안

**가격** : 2,000원

엔진이 아르테미스 엔진에서 피니엔진으로 변경되며, 아래와 같은 사항이 변경이 됩니다.

**삭제 되는 부분**

- 타이틀로 돌아가기

- 설정 창에서 퀵 세이브 버튼 삭제 (필요 없다고 판단)

**추가 되는 부분**

- 게임 종료

- 세이브 슬롯 증가 (고려중)

- 게임 창에 AUTO MODE 버튼 추가

- 게임 창에 SKIP MODE 버튼 추가

- 게임 창에 BACKLOG 버튼 추가

---

실제 어떻게 될지는 모르겠지만, 버튼의 배열이 달라져 곤란해 하는 경우가 생길까봐 미리 공지합니다.

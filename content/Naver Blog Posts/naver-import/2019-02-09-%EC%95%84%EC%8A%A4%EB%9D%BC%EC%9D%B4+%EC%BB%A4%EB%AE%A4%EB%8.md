# 아스라이 커뮤니케이션의 발매일을 공개합니다.

**아스라이 커뮤니케이션** / Project 22

가격 : 3,900원

발매일 2월 16일 (토)

안녕하세요, **Team HC 하언**입니다.

오늘은 아스라이 커뮤니케이션의 발매일을 공지합니다.

개발도 막바지에 이르렀습니다.

게임의 완성이 아닐까 싶습니다.

오류도 없고, 루트 분기도 다 테스트 해보았습니다.

사실 모든 게임이 이렇게 테스트를 해보지만 항상 문제가 발생하더군요.

긴 시간 동안 개발한 만큼 여러가지 추가 기능도 있으며, 이 게임만의 독특한 재미도 느끼실 수 있으실 거라 생각됩니다.

플레이 하는 여러분들 모두에게 캐릭터들에 대한 애정이 생기길 기원하며 개발한 게임입니다.

응원해주신 여러분들께 다시 한 번 감사의 인사 올리면서.

하단은 스크린샷입니다.

그럼 발매일에 다시 만나요!

일주일만 더 기다려주세요!!

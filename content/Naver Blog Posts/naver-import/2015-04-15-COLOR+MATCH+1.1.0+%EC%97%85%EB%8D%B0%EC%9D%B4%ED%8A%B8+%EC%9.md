# COLOR MATCH 1.1.0 업데이트 안내.

**Ver 1.1.0**
**노멀모드**의 색 전환이 20에서 15로 조절
노멀모드의 시작 게이지가 50에서 40으로 조절
노멀모드의 최저 게이지를 20에서 15로 조절
노멀모드가 이제 버튼을 클릭해도 체력이 완전 차지 않고 25% 오르는 것으로 변경.
노멀모드에 이제 피버가 추가 됩니다. 이 피버는 버튼을 맞출 때마다 오르며 피버가 발동이 되면 모든 게이지가 회복이 됩니다.

게이지가 회복 된 뒤에는 좀 더 많은 피버가 필요로 하게 됩니다.

이제 노멀모드가 좀 더 발랄하게 바뀌었습니다.

**하드모드**의 **삭제** -> 하드코어모드로 통합.
**하드코어모드** 최저시간 12에서 9로 조절
하드코어모드의 색 전환이 15에서 12로 조절
하드코어모드가 이제 버튼을 클릭해도 체력이 완전 차지 않고 20% 오르는 것으로 변경.
이제 하드코어모드가 좀 더 어둡게 바뀌었습니다.

**반대반대모드**의 추가. 시작 게이지 100, 최저 게이지 20, 시간 감산값 3.
반대반대모드는 상단에서 내려오는 것과 다른 색을 클릭해야 합니다.
단 한 번 클릭한 색상은 다른 색상을 눌러야 누를 수 있으며 2개가 연달아 내려올 경우 다른 색상을 번갈아 눌러야 합니다.

가끔 결과값이 표시 안 되던 문제가 해결.

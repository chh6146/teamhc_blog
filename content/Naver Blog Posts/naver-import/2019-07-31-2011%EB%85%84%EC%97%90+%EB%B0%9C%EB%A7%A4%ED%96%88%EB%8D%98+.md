# 2011년에 발매했던 미궁 시리즈가 구글 플레이에서 내려가게 되었습니다.

안녕하세요, **Team HC 하언**입니다.

첫 번째 미궁이었던 Project 1과 두 번째 미궁이었던 Project 3는 구글 플레이에서 내려가게 되었습니다.

사유에 대해서 여러가지로 조사해보고 알아본 결과 원인은 '네이티브 코드'로 만든 게임이었기 때문입니다.

Project 1도 그러하고, Project 3도 그러하지만 내부에 html파일을 내장하여 Webview를 이용해서 문서를 출력하는 형태로 게임은 만들어져 있습니다.

그런데 이 Webview가 안드로이드 내에서 보안 문제로 사용 되지 않은 게 꽤 되었던 모양입니다.

따로 엔진을 이용한 것도 아니고 더불어 Project 1, 3 일부 소스가 분실 되었고 안드로이드 스튜디오에서 추츨할 때 필요한 Key까지 모두 분실 되었습니다.

그렇기 때문에 따로 업데이트도 불가하며 어쩔 수 없이 내리게 되었습니다.

미궁 시리즈에 대한 애착은 상당히 깊습니다.

그렇기 때문에 이대로 내리는 것도 너무나 아쉽고, 미궁 시리즈는 꼭 한 번 리메이크를 해야겠다라고 생각을 했기 때문에

렌파이 엔진을 이용해서 남아 있는 소스를 활용해 리메이크를 할 계획입니다.

원작에 있던 문제의 경우는 답이 분실 되어있는 경우도 있고, 해답이 분실 되어있는 경우도 있고.

지금 풀기에는 시대상 어울리지 않는 문제들도 다수 포함 되어있기 때문에 대다수 새로운 문제들로 바뀔 예정입니다.

발매일은 정해지지 않았지만 게임성을 좀 더 갖추고 발매하기 위해 많은 시간을 투자해서 개발할 계획입니다.

더불어 어떻게 봐도 내 인생은 너무 불행하다 EP1도 게임은 거의 완성 되어있지만 연출적인 보완, 기타 시나리오 보완에 대해서

확실하게 만들기 위해 좀 더 시간을 투자해서 개발할 계획입니다.

개발하는 동안 틈틈히 근황은 네이버 블로그에 올라갈 계획입니다.
